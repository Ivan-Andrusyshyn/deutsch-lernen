# Wortzeit Duo — дві мови крок за кроком

Мобільний Angular-застосунок з українським інтерфейсом для вивчення німецької або англійської. У кожному мовному режимі доступно 1000 карток із перекладами українською; частина іменників має окремі картки для форм однини й множини. Німецький режим додатково містить розмовні фрази й короткі тексти рівня A2.

## Структура коду

- `src/app/core` — спільні моделі домену.
- `src/app/features/learning` — сторінка навчання, дані словника, фрази й тексти.
- `src/app/shared` — повторно використовувані компоненти та їхні стилі.

## Запуск

```bash
npm install
npm start
```

Відкрийте `http://localhost:4201/`. Для production-збірки виконайте `npm run build`; проєкт підтримує Angular SSR.

### Фото Pixabay

Картки завантажують тематичні фото Pixabay лише біля видимої області екрана. Результати пошуку сервер кешує на 24 години; якщо API недоступне, показується тематична ілюстрація. Ключ API зберігається тільки в кореневому `.env` у змінній `IMG_TOKEN` (або задається в середовищі Node-сервера). Не додавайте його до Angular-коду, Git або повідомлень.

Створіть файл `.env` у корені проєкту з таким рядком:

```dotenv
IMG_TOKEN=your-pixabay-api-key
```

Файл `.env` виключений із Git. Для локальної розробки після збірки запустіть SSR/API-сервер у першому терміналі:

```bash
npm run build
npm run serve:ssr:deutsch-kompass
```

У другому терміналі запустіть Angular dev-сервер командою `npm start`. Він пересилає `/api` запити на сервер `localhost:4000`. SSR-команда завантажує `.env` через Node.js `--env-file` (Node.js 20.6+); у production задайте `IMG_TOKEN` у середовищі Node-сервера. Для сумісності також підтримується `PIXABAY_API_KEY`.

## Можливості

- Виразний вибір мови навчання: німецька або англійська; назви категорій та інтерфейс лишаються українською.
- Пошукові метадані українською та картка структурованих даних для освітнього вебзастосунку.
- Пошук за словами мовою навчання або за українським значенням, тематичні фільтри.
- Окремий прогрес, щоденна мета й мовний щоденник для кожної мови.
- Світла й темна теми зі збереженням налаштувань у браузері.
- Навчальна картка зі свайпами, підказкою, позначкою вивченого й заохочувальним відгуком.
- Лічильник вивчених слів, щоденна мета, серія занять і обране.
- Практика розмовних фраз і короткі тексти A2 з перекладом та запитаннями.
- Прогрес і налаштування зберігаються локально в браузері та доступні після перезапуску.

Застосунок не потребує облікового запису чи сервера для збереження прогресу. Дані доступні лише в тому браузері, де ви навчаєтеся.
